# SVM Kernels on Sleep Health & Lifestyle Dataset
 
Compares Linear, RBF and Sigmoid SVM kernels for predicting `Sleep Disorder`
(None / Sleep Apnea / Insomnia) using scikit-learn pipelines.
 
## Run in Google Colab
1. Open `SVM_Sleep_Health.ipynb` in Colab (File > Upload notebook, or open from GitHub).
2. Run the first cell and upload `Sleep_health_and_lifestyle_dataset.csv`.
3. Run the remaining cells in order.
## Results (test set, 75 samples)
| Kernel | Accuracy |
|---|---|
| Linear | 94.67% |
| RBF | 97.33% |
| Sigmoid | 89.33% |
